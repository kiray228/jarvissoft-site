# jarvissoft.kz

Сайт ТОО «JARVIS SOFT»: услуги, продукты (MyTender, SuperMind), заявка на разработку. Статический, публикуется на GitHub Pages при каждом push в main.

Форма заявки отправляет данные в API MyTender (`https://mytender.kz/api/orders`), там jarvissoft.kz уже разрешён в CORS.

Перенесён из `MyTender/jarvis-site` (раньше был на Vercel: jarvis-soft.vercel.app).
